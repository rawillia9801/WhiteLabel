# New breeder launch checklist

- [ ] Use a new Supabase project and storage bucket.
- [ ] Generate unique admin, portal, CRM, webhook, and email credentials.
- [ ] Set brand identity, contact details, colors, assets, locale, currency, and timezone.
- [ ] Enter the breeder's actual prices and payment rules.
- [ ] Disable modules the breeder will not use.
- [ ] Replace all sample email, contract, application, health, delivery, and refund language.
- [ ] Have local counsel review customer-facing terms and required notices.
- [ ] Test staff login, application, customer portal, document upload, signing, payment, email, and backup flows.
- [ ] Confirm mobile layout, accessibility contrast, domain, favicon, and social preview.
- [ ] Import only records the breeder is authorized to process.
- [ ] Document support ownership, backups, retention, breach response, and offboarding.
